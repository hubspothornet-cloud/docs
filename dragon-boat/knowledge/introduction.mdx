Our Dragon Boat Knowledge section turns selected material from the Hornet blog archive into structured, evergreen guides and case studies.

These pages are not word-for-word copies of the original posts. Each guide is reorganized for clearer answers, easier navigation, and long-term usefulness while preserving the original author, publication date, and source link.

<Note>
  Coaching terminology can vary between teams. The technique pages explain the named coach's framework and should be read in that context.
</Note>

## Editorial Approach

We use the blog and documentation for different purposes:

- The blog preserves original publication dates, announcements, event reports, and stories.
- The documentation provides current, structured explanations and connects related guides.
- Historical source links remain visible so readers can trace each page back to the original record.
- Only articles that add lasting educational or historical value are developed into this knowledge section.
