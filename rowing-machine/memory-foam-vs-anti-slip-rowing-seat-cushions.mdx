## Which cushion should you choose?

Choose the [Anti-Slip Rowing Machine Seat Cushion](https://www.hornetwatersports.com/products/anti-slip-rowing-machine-cushion-high-performance-designed-for-concept-2-machine) when the main concern is reducing movement, selecting Regular or XL coverage, or keeping the cushion lower profile.

Choose the [Thick Memory Foam Rowing Machine Seat Cushion](https://www.hornetwatersports.com/products/memory-foam-cushion-made-for-concept-2-rowing-machine) when maximum padding is the priority. It is Hornet's thickest rowing cushion at 1.88 inches and has a wider 13.25 by 10.25-inch seating surface.

## Product notes

### Anti-Slip Rowing Machine Seat Cushion

The Anti-Slip Cushion uses silicone printing on both the top and bottom to help reduce movement between the rower, cushion, and machine seat. The Regular and XL variants use a sports-grade SBR core and neoprene exterior.

Choose Regular for standard coverage. Choose XL for a larger seating surface and slightly more padding.

### Thick Memory Foam Rowing Machine Seat Cushion

The Thick Memory Foam Cushion uses a supportive memory foam core, neoprene exterior, and anti-slip silicone printing on the bottom. Its foam has a firmer, supportive feel and gradually conforms during use rather than feeling like a loose pillow.

Its wider shape supports the added thickness and provides the broadest seating surface among Hornet's indoor rowing cushions.

## Seating-height tradeoff

A thicker cushion is not automatically the best choice for every rower. The Anti-Slip Regular is 0.5 inch thick and XL is 0.63 inch thick. The Thick Memory Foam Cushion is 1.88 inches thick.

Choose the Thick Memory Foam Cushion when maximum padding matters more than minimizing added height. Choose Anti-Slip when grip, size choice, and a lower-profile setup matter more.

## Machine compatibility

Both products are designed for use with many popular rowing machines, including Concept2, Hydrow, WaterRower, Peloton Row, Sunny Health, and other machines with compatible seat dimensions. The Anti-Slip Cushion is also positioned for Merach and similar rowers.

Customers have reported using the Thick Memory Foam Cushion on Aviron, NordicTrack, ProForm, Pooboo, and other machines. Seat shapes vary, so compare the selected product dimensions and shape with your exact seat before ordering.

## FAQs

### Is the Thick Memory Foam Cushion thicker than the Anti-Slip Cushion?

Yes. The Thick Memory Foam Cushion is 1.88 inches thick. Anti-Slip Regular is 0.5 inch and Anti-Slip XL is 0.63 inch.

### Which cushion has more size options?

The Anti-Slip Cushion has Regular and XL variants. The Thick Memory Foam Cushion has one size.

### Which cushion has grip on both sides?

The Anti-Slip Cushion has silicone printing on both the top and bottom. The Thick Memory Foam Cushion has silicone printing on the bottom.

### Does either cushion attach with straps or clips?

No. Both are strap-free and rest directly on the rowing-machine seat.

### Is the memory foam soft or firm?

It has a supportive, firmer memory-foam feel. It gradually conforms during use and is designed to provide substantial padding without immediately bottoming out.

### Why is the Memory Foam Cushion wider?

Its 13.25 by 10.25-inch surface supports the added 1.88-inch thickness and provides a broader seating platform.

### Will the Memory Foam Cushion raise my seating position?

Yes. It raises seating height more than the lower-profile Anti-Slip variants.

### Do these cushions fit rowers besides Concept2?

Yes. They are designed for use with many branded and generic rowing machines when the seat dimensions and shape are compatible. Compare measurements before ordering.

### Can the Thick Memory Foam Cushion be used on a recumbent exercise bike?

Some customers have reported using it on recumbent exercise bikes. Compare the 13.25 by 10.25-inch cushion shape with the bike seat before ordering.
