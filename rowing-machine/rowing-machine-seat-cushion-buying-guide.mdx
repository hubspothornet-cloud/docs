## How to choose

### 1. Start with the problem

If sliding is the main issue, start with an anti-slip product. If padding is the priority, start with the memory foam option. If seat shape is the priority, start with the cushion whose product page best matches your machine seat.

### 2. Choose Size and Thickness

The Anti Slip Rowing Machine Cushion comes in Regular and XL. The Memory Foam Cushion is almost 2 inches thick and is our thickest rowing cushion.

A thicker cushion changes your seating height more than a lower-profile cushion. Choose Memory Foam when maximum padding is the priority. Start with the Anti Slip or snug-fit Concept2 option when you want added seat support with less change to your rowing position.

Confirm the exact dimensions of every option before buying.

### 3. Confirm Machine Fit

Hornet rowing machine cushions fit Concept2 and many other common rowing machines. Compare product dimensions against your rower seat if fit is critical.

### 4. Keep Product Expectations Practical

Use these products as seat cushions and training accessories. A cushion may change seat feel, grip, or padding, but it should not be treated as a medical product or a guaranteed solution for pain or injury.
